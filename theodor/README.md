# FUNZONE

A playful, dependency-free arcade for quick games, random ideas, and daily challenges.

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension for a local web server. The site uses plain HTML, CSS, and JavaScript; no build or install step is needed.

Progress, settings, badges, and best scores are saved in the browser with `localStorage`. The games work offline; Google Fonts load from the web when available and fall back to system fonts otherwise.

## What's inside

- Seven playable mini-games: Rock Paper Scissors, Number Detective, Tic-tac-toe, Memory Match, Reflex Rush, Click-o-matic, and Trivia Pop.
- Random activities, jokes, facts, challenges, Would You Rather prompts, Truth or Dare, and conversation starters.
- Daily challenges, points, badges, a visit streak, and a sample leaderboard.
- Responsive dark/light themes, optional sound, surprise button, and keyboard easter egg (`F`).
